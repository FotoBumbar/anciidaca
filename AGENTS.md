# AGENTS.md

Romantic private site for David & Anči (Serbian UI, Latin script). **Continue from `PLAN.md`** — milestone 1 (UI surface) is done; next is milestone 2 (Netlify Database).

## Stack
TanStack Start + React 19, Tailwind 4 (theme in `src/styles.css`), shadcn/ui in `src/components/ui`, sonner toasts, lucide icons. Netlify via `@netlify/vite-plugin-tanstack-start`.

## Layout
- `src/routes/index.tsx` — home (hero rotator, counter, film, stages, book teaser)
- `src/routes/album.tsx` — stages (by month), custom albums, videos; opens `Lightbox`
- `src/routes/knjiga.tsx` — book: cover, PDF, chapters, poems, quotes, chapter editors, print-to-PDF section (`.print-only`)
- `src/routes/podeli.tsx` — public read-only share page (no gate); album encoded in `?a=` (base64 JSON `{t, p: ids[]}`)
- `src/components/Shell.tsx` — wraps private pages: `Gate` (code 2703), nav, floating hearts, footer
- `src/components/Photo.tsx` — `DriveImg` (lh3 URL with drive thumbnail fallback), `FitPhoto` (contain + blurred backdrop), `PhotoRotator`
- `src/components/Lightbox.tsx`, `PhotoCard.tsx`
- `src/data/photos.ts` — Drive helpers, stages, special days, per-photo "personality" (deterministic hash)
- `src/data/drive-photos.json` — generated by `scripts/sync-drive.mjs` (public `embeddedfolderview` scrape; RAW .NEF skipped)
- `src/data/book.ts` — quotes/poems/chapters extracted from `public/docs/knjiga-bez-tacke.pdf`
- `src/data/store.ts` — **the stub persistence module** (localStorage). Swap its internals for Netlify Database server functions; keep the `useStore()` / `actions` API.

## Conventions / decisions
- Photos must NEVER be cropped: use natural `<img>` height (CSS columns masonry) or `object-contain` with a blurred backdrop. Don't use `object-cover` on the real photo.
- Drive images are loaded straight from Google (not the Netlify Image CDN) to keep bandwidth/transform costs at zero.
- The 2703 gate is symbolic (client-side); real protection comes with Netlify Identity in milestone 3.
- Anything touching localStorage runs in effects (SSR-safe); `Shell` renders nothing until the gate state is known.
- Copy is Serbian, warm, with emoji.
